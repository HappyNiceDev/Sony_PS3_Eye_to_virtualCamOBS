# Sony PS3 Eye to virtualCamOBS

---

## English description

A Python utility that automatically detects a PS3 Eye camera and streams its video feed to a virtual camera using OpenCV and pyvirtualcam.
The application runs silently in the Windows system tray, allowing the PS3 Eye to be used as a video source in applications that support virtual cameras, such as OBS Studio, Zoom, Discord, and Microsoft Teams.
### Features
* Automatic PS3 Eye camera detection.
* Virtual camera creation for Windows.
* Silent background execution.
* System tray icon for easy control.
* Automatic video resizing to 640x480 at 30 FPS.

Perfect for repurposing a PS3 Eye as a webcam for modern applications.

## Descripción en español

Herramienta en Python que detecta automáticamente una cámara PS3 Eye y retransmite su video a una cámara virtual utilizando OpenCV y pyvirtualcam.
La aplicación se ejecuta en segundo plano con un icono en la bandeja del sistema de Windows, permitiendo utilizar la PS3 Eye como fuente de video en aplicaciones compatibles con cámaras virtuales (OBS, Zoom, Discord, Teams, etc.).
### Características
* Detección automática de cámaras PS3 Eye.
* Creación de una cámara virtual compatible con Windows.
* Ejecución silenciosa en segundo plano.
* Control mediante icono en la bandeja del sistema.
* Redimensionado automático de la imagen a 640x480 @ 30 FPS.

Ideal para reutilizar una PS3 Eye como webcam en aplicaciones modernas.
